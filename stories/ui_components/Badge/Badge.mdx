# Badge

The `Badge` component is used to display small status indicators, labels, or counts in a compact format. It helps highlight important information without overwhelming the UI.

### Usage Examples
  - Status Indicators: Show labels like "Active", "Pending", or "Offline".
  - Counters: Display notifications or unread message counts (e.g., 5).
  - Category Tags: Label items with categories such as "New", "Sale", or "Beta".
