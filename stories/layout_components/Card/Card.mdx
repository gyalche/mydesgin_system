# Card

The layout `Card` component provides a structured container for displaying grouped content in a visually distinct way. It is designed to maintain consistent spacing, alignment, and styling while being flexible enough for various use cases, such as dashboards, user profiles, or data displays.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { Card } from '@d-lighted/receptionist-design-system';

const MyExample = (props) => {
  return <Card>My card content</Card>;
};

export MyExample;
`}/>
