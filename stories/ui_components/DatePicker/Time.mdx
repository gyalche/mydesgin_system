# TimePicker

The `DatePicker.Time` component allows users to select a time from a dropdown interface. It provides a user-friendly way to input times in forms and other UI elements.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { DatePicker } from '@d-lighted/sherpa-design-system';

const MyExample = () => {
  return <DatePicker.Time onChange={(time) => console.log(time)} />;
};

export default MyExample;
`}/>

## Features

- Time selection with hour and minute dropdowns
- 12-hour or 24-hour format
- Time range selection
- Customizable time intervals
- Keyboard navigation
- Form integration

## Basic Usage

The basic TimePicker allows selection of a single time.

<Canvas
  of={TimeStories.Time}
  language="jsx"
/>
<Controls of={TimeStories.Time} />

## Time Range Selection

Enable the `isRangePicker` prop to allow selection of a time range with start and end times.

## 12-Hour Format

The `is12Hour` prop enables 12-hour time format with AM/PM selection.

- Fully keyboard navigable
- Screen reader friendly
