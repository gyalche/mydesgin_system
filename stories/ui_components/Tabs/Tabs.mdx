# Tabs

The `Tabs` component allows users to switch between different sections of content within the same view. It enhances navigation by keeping related content grouped together while maintaining a clean and organized UI.

# Tab

The `Tab` subcomponent represents an individual selectable item within a Tabs container. Each Tab corresponds to a specific section of content, allowing users to switch between different views seamlessly.
