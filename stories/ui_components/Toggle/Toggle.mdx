# Toggle

The `Toggle` component is a UI switch that allows users to enable or disable a setting with a single action. It is commonly used for preferences, feature toggles, and on/off controls in settings and interactive UIs.

<Source
  dark
  language="jsx"

const MyExample = (props) => {
  return <Toggle />;
};

export MyExample;
`}/>
