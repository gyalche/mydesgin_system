# Button

The `Button` component is a key interactive element used for triggering actions, submitting forms, and navigating users within the application. It comes in multiple styles and sizes to fit different use cases.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { Button } from '@d-lighted/sherpa-design-system';

const MyExample = ({onClick}) => {
  return <Button onClick={onClick}>Button</Button>;
};

export MyExample;
`}/>

The props declared inside the component allow customizing several options.
