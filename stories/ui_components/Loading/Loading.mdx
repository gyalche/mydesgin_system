# Loading

The `Loading` component is used to indicate that content is being loaded or a process is in progress. It provides visual feedback to users, improving the perceived responsiveness of the application.

### Usage Examples
  - Page Loading: Display a full-page spinner when fetching data.
  - Button Loading: Show a loading state inside a button when an action is processing.
  - Inline Loading: Use a small loader for specific components, like a table or form submission.
