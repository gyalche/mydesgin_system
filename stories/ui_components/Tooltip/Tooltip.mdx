# Tooltip

The `Tooltip` component provides contextual information when users hover over or focus on an element. It helps enhance usability by offering additional details without cluttering the UI.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { Tooltip } from '@d-lighted/sherpa-design-system';

const MyExample = (props) => {
  return (<Tooltip><Icon name="global-circle-exclamation" /></Tooltip>);
};

export MyExample;
`}/>

The props declared inside the component allow customizing several options.
