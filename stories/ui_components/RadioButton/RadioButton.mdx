# RadioButton

The `RadioButton` component allows users to select a single option from a list of choices. Radio buttons are used when only one selection is permitted, unlike checkboxes which allow multiple selections. They are commonly used in forms, surveys, and settings where users need to choose one option from a set of mutually exclusive alternatives.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { RadioButton, Layout } from '@d-lighted/sherpa-design-system';

const MyExample = () => {
  const [selectedValue, setSelectedValue] = React.useState('option1');

  const handleChange = (event) => {
    setSelectedValue(event.target.value);
  };

  return (
    <Layout.Flex direction="column" gap="8px">
      <RadioButton
        label="Option 1"
        value="option1"
        checked={selectedValue === 'option1'}
        onChange={handleChange}
      />
      <RadioButton
        label="Option 2"
        value="option2"
        checked={selectedValue === 'option2'}
        onChange={handleChange}
      />
    </Layout.Flex>
  );
};

export default MyExample;
`}/>

## Radio Button Group

Radio buttons are most commonly used in groups where only one option can be selected at a time. When one radio button in a group is selected, any previously selected radio button becomes deselected.
