# Checkbox

The `Checkbox` component allows users to select one or multiple options from a list. It is commonly used in forms, filters, and preference settings where users need to enable or disable specific options.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { Checkbox } from '@d-lighted/receptionist-design-system';

const MyExample = (props) => {
  return <Checkbox />;
};

export MyExample;
`}/>

The props declared inside the component allow customizing several options.
