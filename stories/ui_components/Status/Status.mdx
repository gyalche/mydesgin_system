# Status

The `Status` component is used to visually represent the state of an item, process, or user. It provides a quick and intuitive way to convey information like availability, progress, or alerts.

### Usage Examples
  - User Status: Display if a user is "Online", "Offline", or "Busy".
  - Validation State: Indicate stages like "Error", or "Success".
  - Alerts & Warnings: Show critical states like "No data" or "Warning".
