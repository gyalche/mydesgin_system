# Header

The `Header` layout component provides a structured and customizable top navigation bar for applications. It serves as the primary area for branding, navigation, user actions, and quick access to key features.

### Usage Examples
  - Global Navigation: Displays the profile menu, links, and product switchers.
  - Branding & Identity: Includes the product logo.
