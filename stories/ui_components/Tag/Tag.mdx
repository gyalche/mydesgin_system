# Tag

The `Tag` component displays interactive content with remove functionality. It's commonly used in interfaces to show selected items, filters, or categories that users can interact with.

<ContentBlock>
  <Source
    dark
    language="jsx"
    code={`
import { Tag } from 'components/Atoms';

const MyComponent = () => {
  const handleRemoveTag = () => {
    console.log('Tag removed');
    // Your logic to remove the tag
  };

  return <Tag name="Filter" onClick={handleRemoveTag} />;
};

export default MyComponent;
`}/>
</ContentBlock>
