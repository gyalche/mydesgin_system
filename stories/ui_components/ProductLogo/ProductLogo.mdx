# Product Logo

The `ProductLogo` component ensures that company product logos are displayed consistently across the application. It automatically applies the correct format, size, and styling required for headers and other UI placements.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { ProductLogo } from '@d-lighted/receptionist-design-system';

const MyExample = (props) => {
  return <ProductLogo product="Receptionist" />;
};

export MyExample;
`}/>

The props declared inside the component allow customizing several options.
