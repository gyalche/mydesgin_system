# Pill

The `Pill` component is a small, rounded element used to display status, categories, tags, or counts in a compact and visually distinct way. Pills help highlight key information in a non-intrusive manner.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { Pill } from '@d-lighted/sherpa-design-system';

const MyExample = (props) => {
  return <Pill>Pill</Pill>;
};

export MyExample;
`}/>

## Usage

The props declared inside the component allow customizing several options.
