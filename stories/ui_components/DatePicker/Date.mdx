# DatePicker

The `DatePicker` component allows users to select a date from a calendar interface. It provides a user-friendly way to input dates in forms and other UI elements.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { DatePicker } from '@d-lighted/sherpa-design-system';

const MyExample = () => {
  return <DatePicker onChange={(date) => console.log(date)} />;
};

export default MyExample;
`}/>

## Features

- Single date selection
- Date range selection
- Double calendar view for easier date range selection
- Keyboard navigation
- Locale support
- Future date restriction option

## Basic Usage

The basic DatePicker allows selection of a single date.
