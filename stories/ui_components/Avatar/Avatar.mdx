# Avatar

The `Avatar` component represents a user or entity with an image, initials, or an icon. It is commonly used in profiles, comments, chat applications, and dashboards to visually identify individuals or groups.

### Usage Examples
  - User Profiles: Display a user’s profile picture in account settings or comments.
  - Team Members: Show avatars for team members in a list or card layout.
  - System Entities: Represent organizations, bots, or placeholders when no image is available.
