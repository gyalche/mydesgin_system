# DateTimePicker

The `DatePicker.DateTime` component combines date and time selection into a single interface. It provides a comprehensive solution for selecting both date and time values in forms and other UI elements.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { DatePicker } from '@d-lighted/sherpa-design-system';

const MyExample = () => {
  return <DatePicker.DateTime onChange={(dateTime) => console.log(dateTime)} />;
};

export default MyExample;
`}/>

## Features

- Combined date and time selection
- Date selection with calendar interface
- Time selection with hour and minute dropdowns
- 12-hour or 24-hour time format
- Date and time range selection
- Double calendar view option
- Customizable time intervals
- Keyboard navigation
- Form integration

## Basic Usage

The basic DateTimePicker allows selection of a single date and time.
