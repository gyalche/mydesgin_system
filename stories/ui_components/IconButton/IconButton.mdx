# Icon Button

The `IconButton` component combines an icon and text to provide a clear, action-driven button with visual reinforcement. It enhances usability by making actions more recognizable while maintaining a compact design.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { IconButton } from '@d-lighted/sherpa-design-system';

const MyExample = ({onClick}) => {
  return <IconButton onClick={onClick}text="Button" />;
};

export MyExample;
`}/>

## Usage

The props declared inside the component allow customizing several options.
