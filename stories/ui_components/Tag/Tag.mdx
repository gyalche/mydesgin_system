# Tag

The `Tag` component is used to display categorical labels, metadata, or filters in a compact and visually distinct format. It helps organize content and provide contextual information at a glance.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { Tag } from '@d-lighted/receptionist-design-system';

const MyExample = (props) => {
  return <Tag content="Tag" />;
};

export MyExample;
`}/>

## Usage

The props declared inside the component allow customizing several options.
