# Profile

The `Profile` component displays user information such as name, avatar, and additional details. It is commonly used in navigation menus, account settings, and user dashboards to provide quick access to personal information and actions.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { Profile } from '@d-lighted/receptionist-design-system';

const MyExample = ({ account }) => {
  return <Profile account={account} />;
};

export MyExample;
`}/>
