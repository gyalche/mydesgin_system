# Layout

The layout components provide a structured framework for organizing content across an application. They ensure consistent spacing, alignment, responsiveness while maintaining flexibility for different UI needs, and a good code readability.

<Source
  dark
  language="jsx"
  code={`
import * as React from 'react';
import { Layout } from '@d-lighted/sherpa-design-system';

const MyExample = (props) => {
  return <Layout.Block>My content</Layout.Block>;
};

export MyExample;
`}/>

# Block

The layout `Block` component is a versatile, ready-to-use `<div>` element styled with `display: block`. It serves as a foundational building block for structuring layouts while ensuring consistent spacing, and alignment.

## Usage

The props declared inside the component allow customizing several options.

<Canvas
  of={LayoutStories.Block}
  language="jsx"
/>
<Controls of={LayoutStories.Block} />

# Flex

The layout `Flex` component is a versatile, ready-to-use `<div>` element styled with `display: flex`. It serves as a foundational building flex for structuring responsive layouts while ensuring consistent spacing, alignment, and a good set of distribution options.

## Usage

The props declared inside the component allow customizing several options.

<Canvas
  of={LayoutStories.Flex}
  language="jsx"
/>
<Controls of={LayoutStories.Flex} />

# Item

The layout `Item` component is designed to be used inside layout `Block` and layout `Flex` components, providing a flexible and consistent way to structure individual elements within a layout.

## Usage

The props declared inside the component allow customizing several options.

<ArgTypes of={LayoutStories.Item} />
