# Hamro Design System

The Hamro Design System bridges design and engineering by centralising reusable UI components, visual guidelines, and tooling powered by Storybook.

### Install the latest version
```sh
npm install hamro-design-system
```

### Run Storybook locally
```sh
npm run storybook:run
```

---
## Use a local build
If you made changes to the design system and want to test it locally without publishing a package, follow the steps below. [[Documentation](https://d-lighted.atlassian.net/wiki/spaces/Engineers/pages/2733047818/development+local+package)]

1. Uninstall the published npm package.
   ```sh
   npm uninstall hamro-design-system
   ```
2. From the Hamro Design System folder link the package.
   ```sh
   npm link
   ```
3. In the consumer project link to the local package.
   ```sh
   npm link hamro-design-system
   ```
4. After testing, unlink the package in the consumer project.
   ```sh
   npm unlink @d-lighted/sherpa-design-system
   ```
5. Back in the Hamro Design System folder unlink the local package.
   ```sh
   npm unlink
   ```
6. Reinstall dependencies if needed.
   ```sh
   npm install
   ```
