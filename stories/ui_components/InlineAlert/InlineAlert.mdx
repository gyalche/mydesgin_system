# InlineAlert

The `InlineAlert` component provides a way to display brief, non-intrusive alerts within a page or section. It is useful for conveying important messages, warnings, or status updates without disrupting the user's workflow. Inline alerts are typically used for contextual feedback, such as form validation messages, system status updates, or informational notices.

## InlineAlert Types

- **Success**: Used to indicate a successful operation
- **Info**: Used to provide general information
- **Warning**: Used to warn users about potential issues
- **Error**: Used to indicate errors or failures
